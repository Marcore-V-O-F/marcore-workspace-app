# Marcore Workspace

De app voor het team van Marcore: de downloads en de updates.

- **Installeren:** download bij de nieuwste release onder **Assets** het bestand dat eindigt op `_aarch64.dmg`
  (Mac met Apple silicon).
- **Bijwerken:** dat doet de app zelf. Is er een nieuwe versie, dan staat er een knop **Update** op Home.
  Updates zijn ondertekend; de app installeert alleen een update van Marcore.

De code van de app en het werk van het team staan hier niet.
